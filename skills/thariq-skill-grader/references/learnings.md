# Learnings Log

Append-to-top dated log of novel observations captured during grading sessions. Newest entries first. Each entry has structured fields so any future session can parse them. See `references/program.md` for capture criteria and promotion thresholds.

Entry shape:

```
## YYYY-MM-DD — <skill_graded>
- dimension: <rubric dimension or N/A>
- observation: <one-sentence specific pattern>
- candidate_reference: <anti-patterns | description-patterns | exemplars | categories | program | eval-case>
- confidence: <low | medium | high>
- status: captured
```

When promoted or archived, edit the status line in place and append the relevant fields (`promoted_to` + `promoted_at`, or `archived_reason` + `archived_at`).
