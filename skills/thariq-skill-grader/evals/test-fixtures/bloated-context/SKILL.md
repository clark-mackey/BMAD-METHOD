# Bloated Context

## What is JSON?

JSON (JavaScript Object Notation) is a lightweight data-interchange format. It is easy for humans to read and write and easy for machines to parse and generate. JSON is built on two structures: a collection of name/value pairs (an object) and an ordered list of values (an array). Objects are surrounded by curly braces `{}`, and arrays by square brackets `[]`. Values can be strings, numbers, booleans, null, objects, or arrays.

## What is Git?

Git is a distributed version control system. It tracks changes in source code during software development. To use Git, run `git init` to initialize a repository, `git add` to stage files, `git commit` to record changes, and `git push` to send them to a remote. Branches are created with `git branch` and switched with `git checkout`.
